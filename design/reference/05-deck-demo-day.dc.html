Production readiness

Bisa di-deploy hari ini, bukan “nanti setelah dirapikan”.

Infrastruktur sebagai kode

Terraform membangun ulang seluruh sistem dari nol dengan satu perintah.

CI/CD dengan gerbang mutu

Setiap merge menjalankan test, evaluasi agen, lalu deploy. Gagal eval berarti tidak naik.

Batas biaya per tenant

Multi-tenant & aman

Isolasi tenant di setiap query dan log. Secret Manager, redaksi data pribadi sebelum ke model.

Manusia tetap memegang kendali

Balasan bintang 1–2 wajib disetujui manusia. Agen menolak menjawab bila sumber di bawah 0,70.

Specification Driven Development

Spesifikasi dulu. Buktinya ada di riwayat commit.

Kami memakai GitHub Spec Kit apa adanya: constitution, spec, plan, tasks — semuanya di-commit sebelum baris kode pertama ditulis, dan setiap tugas menunjuk ke kriteria penerimaan yang ia penuhi.

Tim kami non-developer. SDD-lah yang membuat AI coding agent menghasilkan sistem yang konsisten, bukan tumpukan tambalan.
